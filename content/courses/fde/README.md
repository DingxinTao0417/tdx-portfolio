# FDE 实战学习专题

网页入口：/learn/fde。中文默认无语言前缀；英文入口为 /en/learn/fde。

## 来源与编辑范围

来源是本机个人知识库中的自编内容包：
D:/workspace/个人知识库/交付/FDE网站内容包-v0.1/。

本目录导入 course.json、questions.json、answer-key.json 和 32 份讲义。
知识库原文件未改动。讲义补充了虚构教学例子、分步操作、可复制模板和产物检查；
题目与参考答案保持原题意。主题覆盖 8 个模块、64 道选择题和 8 个开放案例。
模块 6 的第 2 至 4 课属于选修扩展。

独立学习材料，不是官方培训、职业认证或已验收的客户项目。
不使用真实客户数据，不提供真实企业接口、完整工程脚手架或生产接入权限。
原资料中的时间估计没有作为网页阅读时长或完成承诺展示。
讲义和题库目前为中文；导航、交互提示与教学图有中英文版本。

## 在线练习与隐私

选择题使用原答案集合判分。多选必须选全且不多选，不给部分分。
可以看提示、查看解析、反复练习。答案随所需题目传入浏览器，不能作为防作弊考试。
开放案例提供本页方案文本框、参考思路与自评清单，不自动判分。
文本框不上传、不保存，离开或刷新后清空。

本机记录仅保存读完课节 ID 与曾答对的题目 ID，不保存所选答案、方案正文或个人信息。
localStorage 键：fde-practical-v01:learning-record:1。
支持清空此专题记录。存储不可用时显示提示，并仅保留本次页面会话的内存记录；刷新后未保存的更改可能丢失。
不跨设备同步，不把阅读、自测和项目验收合并成资格结论。

## 教学图片

使用内置 imagegen 生成，先检查第 1 课的架构图与实际页面，再展开其他图片。
共三组主题，每组中英文各一张：

- fde-architecture：身份边界、问答路径、确认后的模拟建单路径。
- fde-retrieval：有效且获准的原文，怎样支持一个保留条件的回答。
- fde-execution：已写入但响应超时的模拟情境，按原动作标识查询，不直接重建。

资产保存在 public/images/learn/。图片只出现在课程介绍与课节内容中，学习列表和首页学习入口不显示教学图片。
图片不裁切，可打开原图。
生成提示词、参考图片、原始产物位置见 docs/fde-visual-assets.json。
原始生成文件保留在 Codex generated_images 目录。

## 课程阅读布局

课程介绍和所有课节共用 /learn/fde 的布局。桌面左侧为固定在阅读区域内的课程目录，
目录可独立滚动、按模块展开收起，显示当前课节和已读标记；右侧保留讲义、教学图和在线自测。
切换课节、展开手机目录或跨越响应式断点时，会将当前课节定位到目录可见范围。
手机与窄屏用可展开的课程目录，选择课节后自动收起。课程介绍不再重复整套目录卡片。
课程介绍与课节详情不渲染全站页脚、联系区块或导航中的额外联系按钮；保留普通导航链接。
学习列表及网站其他页面仍保留页脚与联系按钮，页面间客户端跳转时会自动恢复。
截图对照与交互检查记录见项目根目录 design-qa.md。

## 维护与验证

数据读取仅接受课程目录中的课节，不接受任意文件路径。
修改题目或课节 ID 后，应一并检查答案、导航与本机记录过滤。
课程加入首页、全局导航、FDE 博客内链和 sitemap。

相关检查：

~~~text
node --test tests/fde-quiz.test.mjs tests/fde-content.test.mjs
npx tsc --noEmit
npm run lint
npm run build
~~~

构建成功只说明网站能够构建，不表示教学项目已完成业务验收。
