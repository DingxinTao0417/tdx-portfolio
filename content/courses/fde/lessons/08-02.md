# 部署配置、监控与成本

## 学完能做什么

你能写出隔离部署的配置清单、监控指标和预算停止条件。

## 核心概念

部署配置说明应用使用哪些依赖、资料、模型、权限和服务地址。秘密配置应与公开代码分开，交付脱敏样例；测试与正式环境必须隔离。本课程只演练本地或隔离模拟环境，不授予真实部署权限。

监控同时看业务与系统：任务完成率、引用问题、越权拒绝、工具失败、耗时和资源消耗。成本应以单个完成任务或一段明确时间为单位，包含失败重试与工具调用，不能只看一次回答的价格。

## 情境拆解

虚构企业的助手响应变慢，记录显示模拟接口反复重试。增加模型预算并不能直接解决，应检查接口错误、重试上限和并发。若达到练习预算或调用限制，应停止后续执行并给出明确状态。

对外部模型不可用的情况，可以设计模拟响应以验证权限和异常处理，但必须标注它不代表真实模型效果。固定评测记录应保留配置与资料版本。

## 常见误区

把密钥写进 README 便于运行，会造成泄露。只监控服务存活，可能忽略错误答案和重复工单。收集日志也需脱敏、限制访问并约定保留时间，不能无限保存原始请求。

## 上线依赖需要能被接手者看见

配置、数据版本、接口状态、监控和故障责任都影响运行。只交一个能启动的界面，接手者仍可能不知道为什么某类请求失败。

Token 用量和费用可以帮助发现异常，但不是业务成功指标。失败调用、重试和辅助评判的消耗也应算进同一口径。

## 动手：写一页运行清单

1. 记录代码、提示、资料、索引、配置与接口契约版本。
2. 分开公开样例配置和秘密凭据，交接文件只放占位符与获取方式，不放真实密钥。
3. 为业务完成、延迟、错误、重复动作和用量写监控口径及责任人。
4. 设计两个合成故障，例如检索不可用与接口超时，写出告警、降级和核对办法。
5. 如估算费用，注明模拟参数或实际计费来源与日期，不把教学假设写成供应商价格。

~~~text
运行版本与依赖：
公开配置样例 / 秘密获取方式：
监控指标及分母：
故障信号与触发条件：
降级后允许 / 禁止动作：
处理者与核对步骤：
用量与费用口径：
~~~

### 检查产物

接手者能知道系统用的是什么、怎么看异常、该停止什么。本课仅设计运行方法，不实际连接生产系统或开启付费资源。
