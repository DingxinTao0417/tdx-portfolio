# 内容调整记录 · 2026-09-10

## 语气

当前用途是项目展示与求职。用户本次要求收敛过强的个人主义表达；这取代 2026-09-08 的“强调个人偏好”方向。

- 先说明项目功能、开发范围、实现方法与实践收获。可以使用第一人称，但不以个人好恶、对立口吻或反复免责声明作为介绍重点。
- 保留 AI Native 身份，具体说明 AI 用于实现、审查和问题分析，以及如何验证结果，避免空泛的效率宣传。
- 求职方向与已确认经历分开表述。FDE 是关注的职业方向，不写成已担任的职位；USC 硕士保持在读状态。
- 保留开源来源，尤其 Omnigate 基于 new-api；不把上游功能写成个人成果。
- 使用 humanizer 检查语气，不增加无来源的客户经历、性能成绩或使用规模。

## 本轮范围

- `src/messages/zh.json`、`src/messages/en.json`：首页、关于我、技能、项目与博客入口、联系区域、页脚和页面元信息同步改为职业展示语气。
- `src/data/projects.ts`：四个项目的中英文说明，保留技术栈、职责、截图与链接；Omnigate 的上游归属、As-a 的演示状态和待验收事项不变。
- `src/data/skills.ts`：调整分类说明。保留技术清单与内部视觉权重，不恢复公开自评等级；总述区分接触学习与项目实际使用。
- 中英文 `insights`、`my-usage`、`my-claude-md`：修改标题、摘要和正文语气，收敛绝对结论与未经量化的省时/省钱表述。模型名、提示词及配置代码块保持原样，内部文章链接文字与新标题同步。
- 中英文 `what-a-forward-deployed-engineer-actually-does`：改为角色理解与方法总结，去除无佐证的个人客户经历和业绩数字；角色定义链接至已核对的官方岗位说明。
- `structured-workflows` 保留现有教学示例边界。所有文章的 slug、发布日期、图片及其属性不变；不修改博客搜索、排序与分页功能。
- 新增 `tests/site-localization.test.mjs`，检查中英文消息结构、有效 ICU 语法与插值参数一致性。

## 事实边界与历史材料

- `src/data/timeline.ts` 中的任职条目仍标注为占位资料，About 页面继续不渲染，不能作为真实任职证据。
- 原博客的技术配置和具体模型名称不是本次事实核验范围，不将本轮语气修改描述为全部技术事实已获验证。提示词中的角色设定保留，正文明确不能据此代表公司的实际流程。
- FDE 旧文可从 Git 历史追溯；当前页面只呈现角色学习与已记录的项目实践。

## 验证与交付

- 验证命令：`npm run lint`、`npm run build`、`node --test tests/*.test.mjs`、`git diff --check`。
- 本地预览使用标准 `npm run dev` 的 3000 端口。当前版本不要额外指定 `--hostname 127.0.0.1`：Next.js 的主机名规范化会令中文路径在开发模式下自重定向；使用标准命令已恢复，无需修改路由。
- 本轮仅本地修改，未提交、推送或部署。页面布局、图片、动效、教育数据与既有功能保持不变。
