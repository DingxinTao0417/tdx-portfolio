## 首页 AI 粒子模型（2026-09-08）

- 当前序列替换为 `TDX → 大脑 → 神经网络`，中英文标签、无障碍描述和无 WebGL 时的占位同步更新。T 保持橙色，D/X 统一使用主题中性色。
- 大脑由双半球曲面、中央纵裂、弯曲脑沟及沟侧回脊构成，保留小脑干和少量内部纤维。回脊按弧长采样，独立法线、透明度和粒子尺寸用于保留表面细节。
- 神经网络以粒子球表现节点，隐藏层在空间中展开；连接采用稀疏路径，橙色信号沿输入至输出方向传播。
- 两个模型保持真实 Z 深度并缓慢转动；字母仅保留轻微鼠标视差。表面法线与深度控制明暗，避免背面粒子覆盖前侧细节。
- 桌面使用 11,000 粒子，窄屏或低核心设备使用 7,200 粒子，DPR 上限 1.5；目标数据在挂载时生成，逐帧变形与信号计算在单个粒子着色器中进行。
- 每种造型停留 6.8 秒、形变最长 2.4 秒。点击模型名称可以选择模型；播放中先完成当前形变，暂停时立即显示所选模型。减少动效时默认显示静态大脑，也可选择其他静态模型。
- 本轮验证：`npm run lint`、`npm run build`（35 个静态页面）和独立 TypeScript 检查通过。真实浏览器覆盖 1440×900、390×844、中英文、深浅主题、手动选型、暂停与恢复；窄屏未发现横向溢出。
- 数值验证覆盖 7 档粒子数、位置/样式/法线重排一致性、自动播放与减少动效状态机，以及形变过程和极限视角的投影边界。网络视差限制为 ±0.015、自动转角限制为 ±0.02；272px 画布下，计入抖动和高亮粒子足迹后的最小节点间距约 3.36px。未进行实体低端设备帧率测试。
