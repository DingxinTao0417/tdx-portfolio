# 首页 GitHub 贡献热力图

## 数据与边界

- 数据源为 GitHub 公开贡献日历 `https://github.com/users/DingxinTao0417/contributions`，不是随机数据，也不等同于纯 commit 次数。
- 服务端根据日期格子的 `id` 与 `tool-tip for` 关联读取每日次数，保留 GitHub 的颜色等级；按 UTC 日期排序后校验完整日期范围、每日数量之和与标题总数。
- 缺省展示 GitHub 的滚动一年（首周会向前补齐）；可选择 2023 年至当前 UTC 年的自然年。当前年未来日期只显示空边框，不计为已发生的零贡献日。
- `GET /api/github/contributions` 返回近一年；`?year=2024` 返回指定自然年。非法年份返回 400，上游不可用或格式校验失败返回 503，均不缓存错误响应。
- 服务端 fetch 缓存 1 小时、8 秒超时；React cache 避免同次渲染中与 profile snapshot 重复请求。客户端复用本次访问中已加载的年份，重新打开页面可获取更新后的数据。
- 不需要 GitHub token；浏览器只接收解析后的日期、数量和等级，不注入 GitHub HTML。GitHub 页面结构变化可能导致暂时不可用，届时需更新解析器。

## 展示与交互

- 月份与日期网格使用同样的列宽、间距，并显式固定月份行，避免原实现月份自动换行、错位。
- 悬停、点选显示具体日期与贡献数；格子只占一个 Tab 停靠点。方向键按天/周移动，Home / End 跳到首日/末日。
- 窄屏仅图内横向滚动，初次打开定位最近日期，不改变页面的垂直滚动位置。
- 切换年份中止旧请求，防止迟到响应覆盖新选择；失败时明确提示，并保留上次成功数据。profile/repos 请求失败不会直接隐藏可用的贡献图。
